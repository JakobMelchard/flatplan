# Shortcuts

Press `?` in the app to open this list as an overlay. `Ctrl` is `Cmd` on a Mac keyboard.

## Tools

| Key   | Action                                  |
| ----- | --------------------------------------- |
| `V`   | Select                                  |
| `W`   | Wall                                    |
| `D`   | Door (then click a wall)                |
| `N`   | Window (then click a wall)              |
| `Esc` | Finish the current tool, clear the mode |
| `F`   | Fit everything into the view            |

## Walls

| Key             | Action                                     |
| --------------- | ------------------------------------------ |
| digits, `Enter` | Exact segment length along the cursor axis |
| `Shift`         | Lock to 90°                                |
| `Ctrl`          | Disable grid snap                          |
| `Del`           | Remove the selected wall and its openings  |

## Items

| Key                  | Action                         |
| -------------------- | ------------------------------ |
| `R` / `Shift+R`      | Rotate ±90°                    |
| `Q` / `E`            | Rotate ±15°                    |
| `↑` `↓` `←` `→`      | Nudge 1 cm, with `Shift` 10 cm |
| `Ctrl+D`             | Duplicate                      |
| `Del`                | Remove                         |
| `Shift`+click / drag | Add to selection / box select  |
| `Ctrl+A`             | Select all items               |

## Edit

| Key                      | Action |
| ------------------------ | ------ |
| `Ctrl+Z`                 | Undo   |
| `Shift+Ctrl+Z`, `Ctrl+Y` | Redo   |

## View

| Input                                | Action |
| ------------------------------------ | ------ |
| wheel, pinch                         | Zoom   |
| drag empty space, middle, `Alt`+drag | Pan    |

Drag snapping: 1 cm by default, `Shift` 10 cm, `Ctrl` 0.1 cm. Rotate handle: 15° steps, `Ctrl`
free.
