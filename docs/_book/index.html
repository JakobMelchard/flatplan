Overview

flatplan

2D furniture arrangement planner for the iPad, usable with touch, Apple Pencil, mouse or keyboard. Draw walls, doors and windows, trace a scanned plan, then arrange furniture that stops at walls and door swings. All lengths in cm.

Open flatplan ↗

It is a static web app: vanilla JS with JSDoc types and a Canvas renderer, no build step, no runtime dependencies. Installed to the home screen it works offline; everything you draw stays on your device unless you export it.

Where to start

  • Install & use: add it to the home screen, offline behaviour, updates.
  • Touch & Pencil: gestures, palm rejection, undo and multi-select.
  • Floor plan: walls, plan images, doors and windows.
  • Furniture: the catalog, placing and moving items, snapping.
  • Layouts & data: several arrangements per plan, persistence, export and import.
  • Shortcuts: every keyboard shortcut; ? opens the same list in the app.
